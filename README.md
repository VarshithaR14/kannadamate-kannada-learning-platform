
# KannadaMate – Kannada for Everyone

An interactive platform designed to help non-Kannada speakers learn practical Kannada through everyday vocabulary, conversations, pronunciation and engaging activities.

## Problem Statement

**Problem Statement 01 – Kannada for Everyone**

People who move to or visit Karnataka often face language barriers while communicating in everyday situations. Existing learning resources may not always provide enough practical, situation-based Kannada learning for beginners.

KannadaMate aims to make learning Kannada simple, accessible and interactive.

## Objectives

- Help non-Kannada speakers learn basic Kannada.
- Teach useful words and everyday expressions.
- Improve understanding through English translations.
- Provide pronunciation guidance.
- Encourage learning through interactive practice.

## Key Features

1. **Interactive Lessons**
   - Everyday greetings and introductions.
   - Food, shopping and restaurant conversations.
   - Travel and directions.
   - Emergencies and asking for help.
   - Family, numbers, time and workplace expressions.

2. **Kannada Vocabulary**
   - Kannada words with English meanings.
   - English transliteration for pronunciation.
   - Audio pronunciation where a Kannada browser voice is available.

3. **Daily Kannada Phrase**
   - Learn a useful Kannada phrase each day.
   - Explore additional phrases.

4. **Interactive Quiz**
   - Beginner, Intermediate and Advanced levels.
   - Multiple-choice questions.
   - Instant feedback and explanations.
   - Score and percentage calculation.

5. **Practice Zone**
   - Interactive flashcards.
   - Kannada-to-English matching activities.

6. **Learning Dashboard**
   - Track completed lessons.
   - Track words marked as learned.
   - View lesson completion progress.

7. **Responsive Design**
   - Accessible on desktop and mobile devices.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/VarshithaR14/kannadamate-kannada-learning-platform.git
```

Navigate to the project directory:

```bash
cd kannadamate-kannada-learning-platform
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

http://localhost:5173

### Production Build

Run:

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.

## Progress Storage

Learner progress is stored in the browser using LocalStorage. Progress remains available in the same browser and device unless browser data is cleared.
